## 系统性问题

### 1. 提示泄露答案（120 条）

原提示普遍直接写出读音、中文释义或目标语法结论，学习者无需推理即可抄出答案。现已将 120 条提示全部改为非答案式线索，例如要求观察构词、助词作用、活用位置、上下文对立或敬语关系；不再直接出现完整答案及其主要释义片段。

### 2. 原始关联字段不足

- 本次涉及的原 `learning_exercises.answer` 只是 `A`–`D`，无法脱离选项独立充当教学答案；候选文件中的文字答案必须回到日语原句重新判定。
- 这 120 条原练习的 `vocab_item_id` 为空，不能依靠外键机械核对；本轮按题面中的原文片段与句子、语法点、字幕逐项匹配。
- `learning_sentences.source_line_no` 与 `subtitle_lines` 的实际行号存在偏移，且部分中文字幕发生错位。因此上下文判断以日文文本匹配和相邻日文台词为主，中文字段只作辅助，避免把错位译文写回答案。

## 最终校验

- 三份 JSON 均能成功解析。
- 每份恰好 40 条，总计 120 条。
- 每条都且仅含 `id`、`prompt`、`answer`、`hint`、`review_note` 五个非空字符串字段。
- ID 无重复、无意外缺失或越界。
- 完整答案未出现在提示中；按中文分号、冒号和引号拆分后的主要答案片段也未出现在提示中。
- 没有使用 Python 或其他模板批量生成教学内容；脚本仅用于结构、计数与字符串泄露校验。
