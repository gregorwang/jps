## 复核修正

| 来源 | 修正原因 | 最终处理 |
| --- | --- | --- |
| `sentence-082`「させっねえ！」 | 原答案把省略动作唯一化为“让你继续行动／得逞”，超出残句本身能证明的范围 | 保留粗硬否定使役和拒绝前一句请求的功能；明确省略动词不能仅凭该片段唯一恢复 |
| `sentence-103`「大概にっしろや！」 | 原答案仅凭句末「や」断言“地方色彩” | 改为强烈、角色化的粗硬口吻，不做无充分证据的方言归类 |
| `sentence-107`「価値の有無って話になると…」 | 原答案把奥托贬低昴的回答误写为“自损” | 改为郑重而反高潮的“拆台式回答”，并保留非功利动机的语境解释 |
| `sentence-123`「…って おわあああ！」 | 孤立的「って」在受击中断处无法唯一判定为某一种引用或反驳结构 | 明确其可能是未完片段或被截断的句尾；只保留“发话被攻击中断、后项为惨叫”的确定结论 |
| `sentence-124`「アル･フーラ！」 | 原答案把它和「エル･フーラ」直接判为不同等级或形式，字幕本身不足以证明等级关系 | 仅确认二者是不同术式名及其施术功能；具体等级关系须由作品设定另行佐证 |
| `sentence-132`「どうして スバルは ここにいるの？」 | 原答案把后续身体反应解释成“被排斥／墓所机制”，引入字幕外设定 | 改为昴没有出现罗兹瓦尔那样的 `はじける` 异常身体反应，并据此解释她的惊讶 |
| `sentence-133`「体がはじけないのって？」 | 原答案将 `はじける` 窄化成“被弹开” | 改为“身体爆裂、发生异常反应”，保留名词化「の」和提题「って」的分析 |
| `sentence-134`「はじけてないにしても…」 | 原答案将 `はじける` 窄化成“被弹飞” | 改为没有出现同样强烈身体异常与“并不轻松”之间的让步关系 |
| `sentence-143`「私のこと怒ってないんだ」 | 原答案把助词省略写成两种固定搭配，容易让学习者把未定分析当成定式 | 改为「私のこと」整体提出生气所围绕的人及其行为，并说明口语未明说具体关系标记 |
| `sentence-146`「私 勝手なことしたでしょ？」 | 原答案加入“离开岗位”等字幕未提供的信息 | 收窄为没有说明便独自离开、躲进墓所深处，并保留「勝手なこと」与确认式「でしょ」的解释 |

这些修正均同步记录在相应条目的 `review_note` 中。修正只收窄或纠正教学解释，没有改变练习 ID、顺序、来源映射或五字段格式。
