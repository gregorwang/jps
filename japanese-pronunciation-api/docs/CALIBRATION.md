# 黄金样本与校准指南

当前代码是工程基线，不是完成校准的“专业发音测量器”。TTS 线上冒烟能够验证 API、模型、存储与评分链，但不能替代真人发音样本。

## 样本矩阵

| 类型 | 首批数量 | 主要验证 |
|---|---:|---|
| 清晰母语/原声 | 30–50 | 正确录音稳定高分且无关键错漏 |
| 学习者正常读法 | 50+ | 真实分数分布与可靠度 |
| 故意错词/助词 | 20 | substitution 与 token 定位 |
| 故意漏词 | 20 | deletion / completeness |
| 异常停顿/重复 | 20 | fluency / extra |
| 静音、低音量、噪声、削波 | 20 | 优先 `re_record` |

每条至少标注：句子、说话者类型、录音质量、是否完整、主要错误 token、人工整体等级 1–5。硬阈值只使用两名标注者一致的样本。

## 首版验收门槛

- 清晰母语/原声：总分 >= 90，且无关键错漏。
- 清晰正确学习者：至少 80% 获得 >= 80。
- 整词漏读召回率 >= 90%。
- 明显错词/助词召回率 >= 80%。
- 低质量录音优先 `re_record`。
- 同一 WAV 连续请求 5 次，模型版本不变时总分跨度 <= 3。
- 2–8 秒录音端到端 P95 < 3 秒；必须从生产日志实测。

## 需要调的参数

`wrangler.jsonc` 中的起始值：

| 变量 | 当前值 | 作用 |
|---|---:|---|
| `NOVA_CONFIDENCE_THRESHOLD` | 0.82 | 低于此值触发 Whisper |
| `FALLBACK_ALIGNMENT_MIN` | 60 | 模糊对齐区下界 |
| `FALLBACK_ALIGNMENT_MAX` | 88 | 模糊对齐区上界 |
| `UNKNOWN_RATIO_THRESHOLD` | 0.20 | 未知字符比例触发复核 |
| `RELIABILITY_THRESHOLD` | 0.65 | 低于此值仍给练习分，但明确标记为低可靠度参考 |

调整顺序：

1. 先补课程词典，减少“本来可知却未知”的文本。
2. 再校准音频质量门控，确保坏录音不会进入 ASR 评分。
3. 调整 fallback 条件，使冲突样本得到第二意见，但不要对每条都付出延迟。
4. 调 reliability，优先降低伪精确结论，而不是追求尽量多的 `scored`。
5. 最后调五项分数权重和区间；每次变更递增 `SCORER_VERSION` 并新增 D1 迁移记录。

## 当前线上冒烟观察

一条 Edge TTS 的目标句录音通过真实 Nova + Whisper 链，返回 `scored`、fallback 与逐词时间片。Nova 将部分复合词转写成拆分汉字，并把「廃部」听为「配布」；课程词典把该结果规范为 `はいふ`，评分器将目标 `はいぶ` 定位为疑似不一致。此结果证明错词路径有效，也证明不能用单条合成音频决定正式阈值。

## 发布阶段

1. Shadow：后台计算，不展示给普通用户。
2. Beta：展示总分和“疑似”问题，保留重录出口。
3. Production：黄金样本达标后移除人工 1/2/3 自评。
4. Recalibration：模型或内容域变更后重跑全部黄金样本，递增 scorerVersion。
