# 動きの文法 · 动效规范（v3）

设计画布：https://claude.ai/artifact/9x3RkMeAtAYTN64i8T8HN4 → v3 页「v3 · 动效样片」（在 Play 模式下每格都能重播）。
配套文档：[ASSET_REMIX.md](ASSET_REMIX.md)（素材改造）。

## 0. 总原则

1. **平时几乎不动**：日常操作只做按下反馈和状态切换，时长 90–240ms，**没有弹跳**。
2. **只有 8 个"番剧时刻"给表演**（第 3 节）。每个时刻都像一个镜头：有出场，有落点，**点一下就能跳过**。
3. **动效只用来说明发生了什么变化**，不用来装饰。
4. **减弱动画**：系统开启"移除动画"（`ANIMATOR_DURATION_SCALE == 0`，现有的 `rememberReducedMotion()` 已经在读）时，所有动效直接显示最终状态，循环动画全部停掉，触觉和音效照常。
5. **只对 `graphicsLayer` 做动画**（位移、缩放、透明度、旋转），不要让布局尺寸跟着动画变化；列表里的动画不要触发重新测量。

## 1. 令牌（替换现有 `ui/motion/MotionTokens.kt`）

| 名称 | 值 | 用途 |
|---|---|---|
| `Ease.Standard` | `CubicBezierEasing(0.2f, 0f, 0f, 1f)` | 绝大多数状态切换 |
| `Ease.Decelerate` | `CubicBezierEasing(0f, 0f, 0f, 1f)` | 进场、底部面板滑入 |
| `Ease.Accelerate` | `CubicBezierEasing(0.3f, 0f, 1f, 1f)` | 离场 |
| `Dur.Press` | 90ms | 按下 |
| `Dur.State` | 180ms | 选中、对错描边、标签指示线 |
| `Dur.Sheet` | 240ms | 底部面板、命令面板 |
| `Dur.Page` | 260ms | 换页 |
| `Dur.Stamp` | 220ms | 盖章 |
| `Dur.TypeChar` | 35ms / 字 | 对话框打字机 |
| `Spring.Settle` | `spring(dampingRatio = 1f, stiffness = 600f)` | 拖拽松手后归位（临界阻尼，不弹） |

删掉：`PopOvershoot`、`popSpring`、`NodeUnlock`、`XpCount` 这些多邻国时期的令牌。

## 2. 日常交互

| 交互 | 表现 | 实现提示 |
|---|---|---|
| 墨色主按钮按下 | 缩放到 0.98 + 底色加深 6%，90ms；松手 180ms 回到原状 | `Modifier.pressable()` 统一处理，用 `interactionSource.collectIsPressedAsState()` |
| 漫画字块按下 | 向右下位移 2px，同时 2px 实投影归零（像把实体块按下去），80ms | 投影不要用 `shadow()`，画一个偏移 2px 的底层框，按下时对齐 |
| 标签栏切换 | 顶部 2px 作品色指示线 180ms 平移到新位置；文字字重从 400 变成 700，不做缩放 | 指示线用 `animateDpAsState` 控制 offset |
| 换页（进入二级页面） | 新页从右侧 24dp 处滑入并淡入，260ms；返回时相反 | 保留现有的预测式返回手势（`PredictiveBackHandler`） |
| 底部面板 | 240ms 减速滑入，遮罩 200ms 淡入到 28%；可以下拉关闭，松手后用 `Spring.Settle` 归位 | `ModalBottomSheet` 或自定义 `AnchoredDraggable` |
| 命令面板（搜索） | 从 0.98 放大到 1，同时淡入，160ms；关闭 120ms | 不做位移，避免头晕 |
| 进度线 | 宽度 300ms 过渡；填充色按进度在作品色的浅色和深色之间插值 | `lerp(workLight, workDeep, progress)` |
| 选项选中 | 描边 1px → 1.5px 墨色，180ms | 只变颜色和描边宽度，不改变尺寸 |
| 加载中 | 三个墨色小点依次变深（`・・・`），每个 300ms 错开；超过 2 秒才出现 | 不用转圈，也不用骨架屏闪光 |
| 下拉刷新 | 顶部作品色细线从中间向两边展开 | 不用系统默认的圆形转圈 |

## 3. 8 个番剧时刻

### 01 アイキャッチ 进场（进入一组题时）
| 时间 | 发生什么 |
|---|---|
| 0–300ms | 作品色网点带从左侧滑入（倾斜 12°），`Ease.Decelerate` |
| 120ms 起 | 竖排「第三話」逐字出现：每字从下方 10dp 处上移并淡入，220ms，每字错开 60ms |
| 520ms | 作品印章盖下（同 02 的盖章曲线），轻触觉 `CLOCK_TICK` |
| 0–900ms | 底部进度线线性填满，满了自动进入第一题 |
- 点击任意位置跳过。设置里有开关「进场アイキャッチ」。
- 同一天内再次进入同一话，时长缩短到 400ms（只保留网点带和标题）。

### 02 出席卡盖章「済」（一话学完时）
- 缩放 1.8 → 0.92 → 1，旋转 -24° → -10° → -12°（每个章的最终角度随机取 -14° 到 +8°），透明度 0 → 1，220ms。
- 落下的那一刻：重触觉 `CONFIRM` + 一声短促的盖章音（可以用 Kenney 音效里的 click 类声音）。
- 这是整个 App 唯一的"庆祝"。不放烟花，也不加分数飘字。

### 03 对话框打字机（每道对话框题出现时）
- 名牌从左侧 10dp 处滑入，120ms。
- 台词每字 35ms 依次打出；标点「、」停顿 +120ms，「。」停顿 +200ms，更像说话的节奏。
- 打完之后，右下角 ▼ 上下 3px 呼吸，周期 800ms，一直循环。
- 第一下点击：立即显示整句；第二下点击才进入作答。
- 原声播放时，打字速度和音频时长对齐（总时长 = 音频时长 × 0.9）。

### 04 字块按下 + 飞入（拼句 / 选词）
- 按下：同第 2 节"漫画字块按下"。
- 松手：字块沿直线飞到对话框空格位置，240ms，`Ease.Standard`，无弹跳；原位置留下一个凹陷的空槽。
- 点对话框里已放入的字块：沿原路飞回，180ms。
- 实现：两个位置都用 `onGloballyPositioned` 记下坐标，放一个覆盖层字块做位移动画，动画结束后再更新数据。

### 05 答错 / 答对
- **答错**：选项左右各轻移 6dp 两次，220ms；描边和底色变成错误色，180ms；触觉 `REJECT`。**不闪红屏，不震整个页面。**
- **答对**：描边和底色变成正确色，180ms；关键词的着重号从透明渐变为作品色，300ms；触觉 `CONFIRM`。
- 反馈面板：从底部 240ms 滑入；角色头像从 0.9 放大到 1，淡入 180ms；台词气泡在它之后 80ms 出现。

### 06 つづく 结算（一组题做完时）
| 时间 | 发生什么 |
|---|---|
| 0–90ms | 全屏白闪一下，像动画的切镜 |
| 100ms 起 | 「つづく」逐字从右侧 40dp 处滑入，240ms，每字错开 50ms |
| 全程 | 顶部网点带极慢地向右平移（6 秒走 70dp，循环） |
| 700ms | 「次回予告」卡片上浮淡入，300ms |
| 900ms | 数字（正确率、用时）直接显示，**不做数字滚动** |

### 07 复习翻卡
- 点卡片：绕 Y 轴翻转 180°，320ms，`cameraDistance = 12 * density`；背面是作品色浅底。
- 左右滑动：卡片跟手移动，同时轻微旋转（位移每 100dp 转 4°）；超过 35% 屏宽就飞出，否则用 `Spring.Settle` 回到中间。
- 下一张从卡堆里升起：缩放 0.96 → 1，位移 8dp → 0，200ms。

### 08 底部面板 + 标签栏
- 见第 2 节。选番面板打开时，出席卡里的「済」章**不重放**盖章动画，只有真正学完一话的那一刻才盖。

### 其他细节
- **登录页**：3–5 片花瓣缓慢飘落，每片周期 8–12 秒，透明度 0.85；按「登校する」后，校门插画放大到 1.15 倍并淡出，400ms 衔接到今日页。
- **今日页「今日の一句」**：每天第一次打开时，竖排台词逐字浮现（每字 40ms）；当天再次打开直接显示。

## 4. 触觉与声音

| 事件 | 触觉（现有 `HapticKind` → 常量） | 声音 |
|---|---|---|
| 普通按下 | 无 | 无 |
| 选项选中 | `Light` → `CLOCK_TICK` | 无 |
| 答对 | `Confirm` → `CONFIRM` | `feedback_success.ogg`（Kenney CC0） |
| 答错 | `Reject` → `REJECT` | `feedback_error.ogg`（Kenney CC0） |
| アイキャッチ盖印 | `Light` → `CLOCK_TICK` | 无 |
| 出席卡盖章「済」 | `Confirm` → `CONFIRM` | 一声短促的盖章音（Kenney 包里挑一个 click） |

- 删除所有 `.hla` 触觉文件和 `HlaPlayer`（`Haptics.perform` 里先走 hla 的分支一并去掉），以及 `DuolingoLikeAssetRegistry` 里的多邻国音效；这些都属于要归档的多邻国素材。
- `FeedbackEngine.mascotTrigger()` 这个吉祥物触发逻辑整段删掉。

## 6. 验收

- [ ] 画布「动效样片」里的 8 格，在真机上逐个对照，时长误差在 ±30ms 以内
- [ ] 开启"移除动画"后，所有页面都能正常使用，没有卡在动画中间的状态
- [ ] 答题过程中连续快速点击，不会出现字块重复飞入、面板叠加等状态错乱
- [ ] Pixel 或小米中端机上 `Profile GPU Rendering` 没有持续超过 16ms 的帧
