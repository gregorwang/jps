# 知識电台（爱蜜莉亚讲课）· 交接

2026-10-06 开始。状态：**声音测试中**，App 还没有任何代码。

## 1. 用户要的是什么

- 午睡、散步时戴耳机听。爱蜜莉亚**用中文讲日语**，像老师一样，但要有她的性格和趣味。
- **分轨、自己挑**：一课知识点一轨，单词按 JLPT 级别 50 个一轨（可连成 100）。**不做打开就随便放的电台**，用户原话：没有规划地听不行。
- 午睡模式：后段放慢、渐弱、停止；散步模式：正常音量，可以循环。**不要叫醒。**
- 内容只放学过的东西是我的建议（睡着后学不进新东西，入睡前复习才有用）；节目单本身是全量的，由用户挑。
- 文案最重要。上一版（老师念讲义）被用户骂「跟坐牢有什么区别」。

## 2. 声音

- 日语：照语音包的配方（SBV2 `emilia2` → 句子过 Seed-VC vc44；短的只用 SBV2）。
- 中文：SBV2 只会日语。做法是 **edge-tts 中文女声（免费）→ Seed-VC vc44 转成她的音色**，Seed-VC 不认语言。
- 原声：她自己的台词，`emilia-voice` 卷上 `/vol/dataset2/wavs/<name>.wav`（252 条，已去 BGM、已按字幕裁过）；`emilia.json` 的 296 条在 `/vol/vocals` 也有（去了 BGM，没裁）。
- 测试：`archive-content-sources/emilia-voice/radio_test/radio_test.py`（`tts` → `modal run` → `mix`），三个版本 A 晓伊 / B 晓晓 / C 晓伊 + auto_f0，试听页 `radio_test/listen.html`。
- **结论（2026-10-06）：edge-tts → Seed-VC 不行，用户：「太糟糕了」。** 中文要用专门的模型。下一轮比赛（待用户点头，先报价）：GPT-SoVITS（Modal 卷 `/gsv` 上已有她的模型，直接用中文推理）、IndexTTS2、CosyVoice 2（都是拿她的原声片段做参考的零样本克隆，中文是它们的强项）；最好的那个不够像再微调。
- 界面样板：https://claude.ai/artifact/13G2wTiGsaVLDaDKyza4GP （節目表 / 再生中 / 午睡モード 三屏）。入口打算放在知識 tab 顶栏（耳机图标），自習目次每课也可「听这课」。

## 3. 爱蜜莉亚的说话方式（写文案的风格手册）

来源：`emilia-voice/emilia.json`（用户逐条确认过是她的 296 句，第 26–50 话），带中文的版本在 `radio_test/emilia_lines.json`（`line_map.py` 生成，附带每句含的辞書词、语法点）。

| 特点 | 原话 | 文案里怎么用 |
|---|---|---|
| 拉长音强调 | すご～く怖かったの / ざ～んねん / すご～く上手！ | 夸人、强调时用；中文里写「超～级」 |
| 闹别扭用 もん | ウソじゃないもん！ / ジュースが悪いんだもん | 被（假想的）听众笑话时 |
| 认死理 | ダメなものはダメよ！ / 諦めないで！ | 讲「这样说不对」的地方，这是她的招牌句 |
| 天然、听不懂 | ちょっと何言ってるのか 分かんない | 遇到绕口的语法、自己讲乱了 |
| 说漏嘴后掩饰 | だ…だいじょうび / あ～ 私 目にゴミが入っちゃったかも | 自己讲感动了、说错了 |
| 直接夸 | すご～く上手！ さすが スバル！ | 每轨末尾复习完 |
| 安慰害怕的人 | 怖くて 当たり前のことよ。そんなの情けないなんて思わないから | 难的课、听众可能记不住时 |
| 约定很重 | 約束してくれる？ 裏切らない？ / 約束… 約束があるの | 下一轨预告、「这个不许忘」 |
| 认真、有点自卑但想帅气 | 私は弱虫で 口だけで… / かっこよくしていたいの | 偶尔自嘲「我以前连字都认不全」 |
| 口头禅 なくちゃ | 知らせなくちゃ / やらなくちゃいけないことがある | 讲 なくちゃ 时直接拿来当例句 |
| 说话爱用 の？／でしょ？ | どうして… の？ / 好きでしょ？ | 向听众提问 |

规矩：

- **她是在陪你学，不是在念讲义。** 每段最多两句讲规则，其余是她的反应、吐槽、回忆。规则要一句话能说完（「自己说了不算、只能盼着的事，就接ように」）。
- **例句先找她自己的台词**（`emilia_lines.json` 按 `words` / `grammar` 查），有就放原声，再让她讲「那时候……」；没有才用生成的日语。原声是这个电台最好玩的地方。
- 中文里夹日语感叹词（えへへ、もう、ね、すご～く）要单独切成日语段，用 SBV2 念，别让中文 TTS 念假名。
- 例句、讲法逐句核对，**讲错不行**（同知识卡的规矩）。
- 不写「同学们好」「今天我们来学习」这种开场；开场是她的一句话或一个小情景。
- 她叫听众「你」，不叫スバル。

## 4. 原声能覆盖多少

`line_map.py` 的统计（粗略，正则）：296 句里有 **301 个辞書词**（N5 126 / N4 90 / N3 58 / N2 21 / N1 4）；语法上多的是 って、可能形、の？、ている、てくれる（29）、たい、被动、なんて、なくちゃ（10）、てあげる（9）、もん（8）；ように、ようになる 各只有 1 句。所以単語轨的 N5–N4 能有不少原声；知識轨大部分要靠生成的日语，原声是点缀。
