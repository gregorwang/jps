## 未发布 · 2026-10-09 · 自習：第十巻 指示

**为什么做**：《日语为什么没有 the / a》这篇文档讲的是「日语靠什么区分新旧、指的是谁」，看番最常卡的 その / あの、俺 / 僕、省掉的主语都在这里。照第五〜九巻的做法做成交互教科書。

### 自習 → 书架第十本「指示」（15 课）
- **一 冠詞のかわり**：が → は 就是 a → the（桃太郎开头）；「は＝the」会翻车的四种情况；ある・とある・という・一人の 怎么引出新角色；什么时候要 その、什么时候光杆名词就够。
- **二 こそあど**：四个词根 × 六个零件连线；现场按「人」分（博士说これ、助手说それ）；**その人？あの人？**——先问听者知不知道（原作台词挑空）；ど＋か・も・でも；そ 为什么撑起了整个接续词系统、こんなに / そんなに / あんなに、あれ？是不是在指东西。
- **三 人称と省略**：お母さん、ベティー、先生 都能当「我」；貴様、てめえ 怎么从敬称掉成骂人话；ワシ・わたくし・妾・てめえ 一开口认角色；it 的六份工在日语里各去了哪；中文腔找错（一つの、それを、彼は彼が、彼女と）。
- **四 読解の指示語**：「これ」「こうした〜」「次の点」指的是哪一句；その→この 说明作者要开始批评；同社・同市・同種 的模擬問題；一段小说、一段说明文里逐个名词补 a / the。
- 44 句是两部番的原台词（33 句有原声）。原文有一处讲错（「俺＋君 不协调」，其实很常见），课里按正确的写。
- 練習 → 言語学「文法」多了第十本的封面。

### 2026-10-10 · 自習：第十一巻 役割語（13 课）

**为什么做**：《役割語漫谈》讲的是「动漫角色为什么一开口就知道是谁」：博士的 じゃ、大小姐的 ですわ、关西腔、ペテルギウス 的「デス」。这些在番里天天听到，却是现实里几乎没人说的「虚拟日语」。第十巻已经用自称认过角色，这本换成别的角度：句尾、它们从哪来、角色类型背后的刻板印象、同一句话换几个人说、番里的角色为什么这么说话。

- **一 部品**：同一句「我知道哦」，博士、大小姐、武士、关西人、热血少年各怎么说（换个人说）；句子里哪块是角色零件、哪块是骨架；**ぞ・ぜ・さ** 各干什么（「行くぜ」是「我要上了」，「一起去」是「行こうぜ」；名词后面 さ 直接接，ぞ・ぜ 要先加 だ）；**わ・かしら・のよ** 是怎么来的（かしら＝か＋知らん；女腔有一半是明治翻译小说造出来的），贝雅特丽丝的 かしら 为什么不是疑问。
- **二 家譜**：だ・じゃ・や 是一家（祖宗是 である，だ 和 じゃ 是兄弟）、为什么老人和博士说 じゃ；いる / おる、ない / ん / ねえ 是东西两家（リューズ 的「会っておらん」、リカード 的「来んかったら」）；**两个 じゃ**（句末＝だ，后面跟 ない＝では）、两个 ちゃう、そりゃ＝それは。
- **三 人物像**：执事的 でございます、侍童シュルト的 であります、女仆弗蕾德莉卡的 ですわ——还有 K-ON 里一听是执事接电话，学姐脱口而出「いらっしゃいますかしら？」；反差（リューズ 小女孩模样说老人腔，律 是女生却说 ぜ）；关西腔的两张脸（Re:ゼロ 的カララギ是商人之国，所以アナスタシア、リカード 说关西腔）；役割語（一类人）和キャラ語尾（ペテルギウス 的 デス、ロズワール 的 だーぁね）。
- **四 聞き方**：先抓骨架，把角色腔还原成标准语（やがる 直接去掉，てやがる 才是 ている）；**人设崩了**——找出大小姐嘴里的 ぜ、执事嘴里的 だぜ；字幕为什么变味：ワシ 配「老身」、俺様 配「本大爷」、妾 配「本宫」。
- 46 句台词里 45 句是两部番的原台词（29 句有原声）；只有「拙者も参るでござる」是例句——两部番里没人说 ござる。
- 原文讲错的 6 处已在课里改正（だ 不是 じゃ 变来的、ない 和 ぬ 不同源、老人腔在江户后期就有了、「行くぜ」不是「一起走」、やっぱ 不是 ら→ん、やがる 不等于 ている），细节在 `KYOKA_HANDOFF.md` 第 7 节。
- 按画布样板改了三处（所有教科書都受益）：**分拣卡**卡面按卡宽定字号，5 个字以上不再在字中间折行（以前 269 张卡里 160 张会折），印章框跟着标签变宽，长标签不再被截掉；**换个人说**的判定行写「你选 B · 正解 A」，不再把两整句抄一遍；**中文选项**改用黑体，不再显示成日文明朝体。

### 2026-10-10 · 自習：第十二巻 訳せない（19 课）

**为什么做**：《听得懂，翻不出来》讲的是那三十几个「字幕翻对了一半」的词：切ない 不是心酸，もったいない 不是浪费，懐かしい 比「怀念」轻得多。原文自己就说别把它们做成单词卡，所以这本不考「中文是什么」，考的是**在场景里分得清它和旁边那个词**。

- **一 心の中**：切ない / 悲しい / つらい 三选一；悔しい（朝前）和 後悔（朝后）、参った；もどかしい・やるせない・いじらしい 三种「卡住」；懐かしい（对人也能说）和 寂しい（本该在的不在，连「懐が寂しい」都算）；恥ずかしい 一个词顶中文四个，羨ましい 当面说只是「真好啊」。
- **二 間柄**：甘える ↔ 遠慮 一根轴（拉近还是推远）、「ご遠慮ください」；気を遣う、空気を読む、野暮 和 粋；仲間 / 味方 / 義理。
- **三 踏ん張り**：しょうがない 的三种用法、なんとかなる 和 なんとかする；頑張って（推）↔ 無理しないで（拉）；同情的档位（かわいそう 是俯视，大変だったね、つらかったね 是平视）、つらい / しんどい / きつい。
- **四 感じ方**：もったいない、せっかく、わざわざ；間、雰囲気、渋い、味がある；かわいい（带点俯视）和 かっこいい。
- **五 決まり文句**：ただいま / おかえり、いってらっしゃい（去了要回来）；よろしく 的五档、おかげさまで、すみません＝谢谢、お疲れ様 和 ご苦労様。
- **六 クッション**：ちょっと…、大丈夫です（＝不用了）、けど… 停住；一応、とりあえず、と思う；やっぱり、さすが、どうせ。
- 63 句台词里 49 句是两部番的原台词（28 句有原声）；切ない、もどかしい、やるせない、いじらしい 这些番里没出现，才写了例句。
- 原文讲错的 6 处已在课里改正（懐かしい 能对人说、切ない 的「切」「ない」、かわいい 不是从 かわいそう 来的、だる 不是 めんどくさい 缩出来的、諦める 来自「明らむ」、ご遠慮ください 的字面），细节在 `KYOKA_HANDOFF.md` 第 8 节。
- 按画布改了**阶梯题**：有一档超过 8 个字时，每档缩进变小，「标准 / 正式」这种标签放到上面一行，日文独占一整行，不再折成两行。第十二巻 第 16 課的 よろしく 五档、第六巻 口語 的命令阶梯（やめていただけますか 那几档）都换成了这个样子。

### 2026-10-10 · 自習：第十三巻 笑い（16 课）

**为什么做**：《笑点是怎么做出来的》是「动漫语言学」系列第二本，接第十二巻。番里的笑点几乎都有个吐槽役在点破（Re:ゼロ 是昴，K-ON 是律和澪），听不出谁在耍宝、谁在吐槽，字幕再准也接不住。原文说笑点是能拆的结构，这本就照着拆：先认出偏离，再认出点破，最后看笑点落在哪一层。

- **一 漫才**：笑声落在「点破」那一下，不在偏离本身——奥托说「友人」，昴接成人名「ユージン」，奥托急了「ユージンじゃなくて友人！」；四种ボケ（天然、とぼけ、勘違い、暴走）：艾姬多娜明知故问被昴拆穿，乐队取名「其实是认真的」被吐槽「本気だったんかい」；吐槽三招（否定、追问、制止）。
- **二 ツッコミの道具**：吐槽的句尾 かよ・だろ・じゃねえ（还有「〜てたまるかよ」其实是「才不会」）；**先接后翻**——ロム爺偷吃零食，昴先得意「そうだろ そうだろ」，再翻脸「って 勝手に食ってんじゃねえ！」，以及昴自己吐槽自己；关西腔为什么是吐槽腔：K-ON 的她们说标准语，吐槽时却喊「何でやねん」「あるんかい」「いただくんかい」。
- **三 笑いの言葉**：すべる・寒い・ウケる・ネタ・ベタ；フリ・オチ・フォロー 三拍（爱蜜莉雅「我才不会说过分的话……不过说你没拖后腿就是说谎了」）；天丼和お約束（雷姆、拉姆一人一句的「立体声」）。
- **四 言葉遊び**：ダジャレ 怎么造（帕克的「名前だけでも覚えて… 逝ってね！」）、听卡分辨谐音梗；数字谐音（4649＝よろしく、0840＝おはよう）和片假名腔。
- **五 アニメの装置**：ガーン・ズコー・チーン 这些拟声词连线；严肃突然松开（さわ子老师训完「这里不是喝茶的地方」，下一秒接过蛋糕；昴的妈妈谈心谈到一半说起栓剂）；メタ発言（「俺の主人公設定は どこ行ったんだよ！」「そのフラグ立てんな ジジイ！」）。
- **六 受け取り方**：弹幕里的 草・神回・尊い；最后一课把一场戏整个拆一遍，再判断笑点在哪一层（画面、结构、双关、文化梗）。
- 52 句台词里 30 句是两部番的原台词（5 句有原声；S2 的原声大多是严肃戏，好笑的少）。原文的例子全是编的，番里没有的（布団が吹っ飛んだ、数字谐音、拟声词）才写例句。
- 原文讲错的 11 处已在课里改正或没用（4989 是「四苦八苦」、0806 拼不出 おはよう、緊張と緩和 是桂枝雀的理论、チーン 是佛坛小铃、天丼的来历……），细节在 `KYOKA_HANDOFF.md` 第 9 节。
- **这本有自己的画法：全书一根线**（照画布 https://claude.ai/artifact/Jg2qJ6cRYYDrBms1GmKijm 做）。直线是常理，偏出去是ボケ，折回来是ツッコミ，笑落在折回来的那一点（作品色圆点，上面一个「笑」）。全部手画，不用头像、气泡、漫画效果：
  - **对话段**（第 1、5、8、9、16 课，12 题）：台词左边一根线，每句上方写是谁说的。作答前线是直的虚线，题目问「哪一句偏出去了？」；揭晓后偏出去的那句整块往右挪，线弯过去，再用一笔粗的作品色折回来，折点变成「笑」。奥托那三句、拉姆的热茶、昴妈妈那句有原声，说话人旁边的小波形点一下就念。
  - **紧张曲线**（第 13 课，3 题）：さわ子老师那段、昴妈妈那段，揭晓后台词上方画出紧张度，一句比一句高，「あん？！」那里裂一下，崩下来那一格是「笑」；台词变成紧凑的一行一句。
  - **四种ボケ**（第 2 课）：台词卡上面多了浅蓝的「前情」条（选完也留着，原来场景写在题干里、选完就没了）；选项是 3 个方块，每个画一种线形——天然 是不知不觉滑出去的弧线，とぼけ 是故意横跨一步的直角，勘違い 是在一个词上走错岔，暴走 是越偏越快冲出框；选完每格下面写为什么。
  - **ダジャレ**（第 10 课）：揭晓后台词下面画「一个音，两条路」：いって 按拍切开，一条通到「行って（记住名字再走）」，一条通到「逝って（记住名字再死）」；ゆうじん 也一样（友人 / ユージン）。
  - **四层楼**（第 16 课）：「笑点在哪一层」的选项画成一栋楼，屋顶下面 画面 → 结构 → 双关 → 文化梗，右边箭头「越往下，越要懂日语」；揭晓后这句台词住进正确的那一层。
  - **課前の一眼**：第 1、5 课的主句换成这根线（编号节点 + 下面的台词图例，第 5 课是唯「只是来吃点心的」→「そっか それなら安心だ」跟着偏 → 「…って 何でやねん！」掉头）；第 10 课是 ふとん / ふっとんだ 按拍对齐：ふ・と・ん 连起来，多出来的 っ 用绿色虚框标「只多一个 っ」（原文说「前两拍相同」是错的）。
  - 连线题左边没有接头时，连错提示改成「对不上：「X」不是这个」（原来是「后面不是这个意思」，对单词配对说不通）。

## 0.30.0 · 2026-10-04 · 自習书架第九巻：読解

**为什么改**：《长难句的真面目，与 N1 读解的"门道"》没有做成纯文字，而是照造語和活用书的做法：先自己动手拆，再揭晓。长句和模拟题的例句都是文档里的原创句，不是台词，所以没有原声，点一下由系统 / エミリア 念。

### 自習 → 教科書书架（往右划，在 見分け 后面）
- **第九巻 読解**（14 課，分四节）：
  - **長い文をほどく**（7 課）：修饰节从哪里开始（只有闭括号，名词在等你）、补洞测试（内の関係 / 外の関係）、の 不一定是「的」（人々の抱く不安）、名词堆叠（把进行・増大・導入 变回动词）、は 管到哪、谓语链和并列、句末一锤定音（ではないだろうか・わけではない・に過ぎない）。
  - **五步で拆す**（2 課）：照原文的五个示范句，一步一步拆（句末定性 → 主题 → 括修饰节 → 骨架 → 放回细节）。
  - **文章の骨組み**（3 課）：主张在哪（靶子、让步、转折、主张）、一篇完整的模拟题（三道题逐项剖析）、毒を見抜く（八种干扰项：无逆过片因主跳问）。
  - **小説を読む**（2 課）：视点和身体（彼は悲しい 为什么不能直接说、肩を落とす 是什么心情）、小说片段（折叠伞那段的心情题、比喻、オノマトペ）。
  - 目次最下面有 **まとめ**「読解の道具箱」。
- **三种新玩法**：
  - **括る / は的地盘**：句子按文节切成块，其中一块是固定的。拖过去（或直接点那一块），经过的块会亮起来，松手就判定；揭晓后把修饰节括进 ［ ］，补洞还原（人が魚を焼く）、内 / 外 的标签和讲解都在下面。
  - **主张はどこ**：一段文章拆成带编号的句子，问「哪一句是作者的主张 / 靶子 / 让步」，点一句。揭晓后每句右边标出它的功能（一般论・让步・转折・主张），信号词加粗，中文在句子下面。
  - **模擬問題 / 毒を見抜く**：原文是可以折叠的卡片（每篇第一题展开）。真题形式：选一个选项，揭晓后每个选项都标 ✓ / 类型 / 为什么；验毒形式：只给一个选项，选它的毒是哪一种，揭晓后把有毒的那几个字划线。依据句直接引在判定下面，不用往回翻。
- 分拣卡片的字号会按字数缩小，「みんなが賛成とは限らない」这样的长词组放得下了。

### 知識 → 多了一组「读解门道」（23 张，在 口语缩约 后面）
接续词地图（两张）、他人的话还是作者的话、考えられる 和 考えられている、设问和反问、对比句型、委婉不等于不确定、命题人的三条约束、正确选项的五个特征、八种干扰项、一票否决六问、同词陷阱、差异定位……要隔一段时间回看的清单放在这里，动手练的放在自習。

- 第九巻学过的课也会进来，五本书的封面排成两列（最后一本单独一行）。

### 原文里讲错 / 说过头的地方（做的时候按正确的写了）
- 连用中止（〜し、）可以有自己的 が 主语，属于 B 类，原文放进了 A 类。
- 主题 は 默认管到**句末**，が・けれど 之类的边界只是「允许出现新的 Yは」，原文说「管到 C 类边界为止」说过头了。

## 0.29.1 · 2026-10-03 · 自習书架第八巻：見分け

**为什么改**：《一张 LINE 截图的「脑内翻译」复盘》讲的核心是「尾巴匹配」——ね・で・い・な・か 这些词尾长得一样、身份不同，看到就套最常见的身份会读错。原文截图内容很沉重，不搬进 App，只用它讲的机制，台词换成两部番的原作。

### 自習 → 教科書书架（往右划，在 類義 后面）
- **第八巻 見分け**（6 課）：台词里标出那个尾巴，选它是谁；再左右划分拣。口诀是「先看左边，再看右边」。
  - ね：死ね 的 ね 是 死ぬ 的命令形，そうだね 的才是终助词。
  - で：自分で（助词）、休んで（て形浊化）、学生で（だ 的连用形）。
  - い：怖い（形容词）、払いなさい・言いたい（动词连用形）、お願い（连用形当名词）。
  - な：行くな（别去）和 行きな（去吧）只差一个元音；そうだな（感叹）、きれいな人（连体）。
  - か：どこか・誰か・何か・いつか 是「某」，句末的 か 才是问号。
  - 藏起来的 く 和 を：ありがとう ← ありがたく、おはよう ← お早く；本も読む 里的 を 被 も 顶掉了。

## 0.29.0 · 2026-10-03 · 自習书架多了三本：助詞、口語、類義

### 自習 → 教科書书架（往右划，在 造語 后面）
- **第五巻 助詞**（10 課）：が・を／に・で／へ・と・から・まで／は・が／も・だけ・しか・さえ／なんて・こそ・でも／ね・よ・よね／かな・っけ・ぞ・ぜ／叠起来、省掉／找错。

  - 命令阶梯：やめろ … やめていただけますか，揭晓后看原作用的是哪一级；再「换个人说」。

- 每本书都有 **まとめ**（目次最下面）：助詞是「格助詞の図式」，口語是融合音和命令阶梯的对照（可以遮住还原那一列），類義是「一个中文词对应几个日语词」的表，点行听台词。

- **时间轴**（ている、てある、ておく、てしまう、ていく、てくる、てから 这几课）：一条「过去 — 现在 — 以后」的线，上面画着点、条、小旗、红叉，看图选词，再放原作那句。

### VOL.D 助动词（12 课）· 積み木 + 凭什么这么说
- **積み木**（せる・れる 两课）：在 食べ 上面一块一块叠 させる・られる・たい・ない・た，只能按顺序叠（顺序不对的积木是灰的），接口会跟着变（たい → たく、ない → なかっ，变了的标蓝），下面实时显示意思（不想被逼着吃）。拼对了放一句同样结构的原作台词。
- **凭什么这么说**（そう、そうだ、みたい・ようだ、らしい、はず、だろう 六课）：上面一句话说明「为什么知道」（自己感觉到 / 听人说 / 按理推），台词挖空，选项分成「看到 / 听说 / 推理」三栏。

- **连线**（第 8、10 课）：左边前半句、右边后半句，先点左再点右，接不上会说为什么；全部连完放出整句。

**起因**：用户提出，最终目标是考过 N2，按一话一话学会让学习的阶梯断掉，是不是应该改成按 N5 → N1 的级别来组织。

**当时查到的数据现状**：

- 单词 3770 个，带 N5–N1 标签（N5 300、N4 468、N3 661、N2 1224、N1 856），但标签是当初 AI 顺手打的：N1 里有「騎士道」「呪術師」「福音書」，N4 里有「ってたの」「ていうか」这种碎片。
- 语法 2966 条，实际只有 1426 个不同句型，级别写法混乱（N4 和 beginner / intermediate 混用），不少条目不是语法点。
- 台词 8560 句，4290 句有原声，大多没有难度标签。
- 已经按知识点组织好的只有自習的 72 课活用。
- 考 N2 约需 6000 词、200 多个语法点，两部动漫的口语台词覆盖不了。

**当时提的方案（大手术）**：以标准 JLPT 大纲为主干，每个知识点优先配原作台词，找不到的用普通例句加 TTS 补；自習改成 N5–N1 五册；練習和復習按级别走；剧集降级成「看番材料」；加定级测试。分三期做，数据最重。

**用户的决定：不做大改。** 理由是这个 App 本来就是以动漫素材为核心收集和组织的，改成以 JLPT 大纲为主干，等于把收集动漫素材这件事本身变得没有意义，产品逻辑反而说不通。

**因此保持现状**：

- 自習仍按知识点（活用 72 课），材料是动漫台词。
- 辞書、課程仍按作品和话组织，練習页里按话的「課程」也保留（审计 A3 就此结案）。
- JLPT 级别只作为辞書里的筛选标签。
- 以后的会话**不要再主动提议改成 JLPT 大纲驱动**。如果将来用户重新提起，上面的数据现状和方案可以直接拿来用。

## 0.10.0 · 2026-09-27 · 产品逻辑大扫除 + 「斩」

这一版把之前攒下的产品逻辑问题一次处理掉，核心是两件事：**练完就结束，不要硬推「再来一回」**；**会的词可以斩掉**。

### 新功能：斩（辞書 · 单词）

看过动漫就会的词（なるほど、ありがとう、大丈夫……）不用再练，可以「斩」掉。斩掉的词：

- 从辞書的词汇列表里消失，也不会再被选进单词练习；
- 如果夹在栞里，会从栞里一起移除；
- 按词本身记（不分哪一话、哪部作品），在一话里斩了，别的话里也不再出现；
- 不会删掉：词汇页顶部多了「已斩 N」，点开能看到全部斩掉的词，展开后点「恢复」就能放回来。

四个入口：

1. **一个词**：辞書 → 词汇 → 点开词条 → 「斩 · 已会」。
2. **一批词**：辞書 → 词汇 → 「選ぶ」，勾选几个词后，底部除了「N 語を練習」还有一个「斩」。
3. **一键斩**：词汇页顶部会显示「动漫里天天听的词 N 个 · 一键斩掉」，一下斩掉这一话里所有这类词。现在内置了约 30 个最常见的（なるほど、ありがとう、すごい、大丈夫、先輩……）；更完整的名单交给 Antigravity 按 3517 个词逐个判断（见下面「数据」）。
4. **学的时候**：单词练习的学习卡底部多了「斩 · 已会」，点了就跳过这个词剩下的题；栞翻卡复习翻开单词卡后，也可以点「早就会了 · 斩」。

### 结算页：练完就结束

以前几乎所有练习的结算页，主按钮都是「再来一组 / もう一回 / 重新练习」，练完了还被推着再练一遍。现在统一成：**主按钮是「完成」（回到进来的地方），「再来」只作为次要按钮，并且只在确实有必要时出现。**

| 练习 | 以前的主按钮 | 现在 |
|---|---|---|
| 辞書 · 单词练习 | もう一回（把同几个词从头再练） | **完成**。答错的词已经在最后重考过一次，并放进了栞 |
| 読空気 | 再来一组 | **完成**；「再来一组」是次要按钮 |
| 活用 復習 | 再来一组 | **完成**；只有还有到期的句子时才出现「再来一组 · 还有 N 句到期」 |
| 基础题库 | 重新练习，旁边还有个莫名其妙的「上一题」 | **完成**；只有答错过才出现「再练一遍」，「上一题」去掉 |
| 課程（按话） | 回到本話 / 再练一次 | 「再练一次」只在有错题时出现 |
| 活用 · 一课的练习 | 下一课 | 不变，另加一个「今天到这」 |
| 自習 | 続き / 次の課 | 不变（本来就是往下走）。「もう一回 了 N 句」这个别扭的标题改成「还要再看的 N 句」 |

另外，一话的課程全部学完后，按钮从「再看一遍」改成「**下一話**」。

### 今日：時間割按主线排

以前「本日の時間割」只按当前这一集排（综合 · 第一話 / 复习 / 读空气 / 跟读），和 App 的主线「自習 → 練習 → 復習」对不上，打开 App 第一眼看不到自習。现在：

- **一限 自習**：接着学的那一课（「第 3 課 · ている」），显示本课学到第几句；**点一下直接开始这一课**，不用再到自習页点第二次。今天学过自習后标成「済」。
- **二限 練習 · 活用**：学过的课里今天到期的句子数，点了直接开始一组。还没学过任何课时不显示。
- **三限 復習**：到期数现在是**卡片 + 栞**的合计（以前只算卡片，数字对不上）。
- **四限 / 放課後**：原来的本集课程、读空气、跟读都还在，排在后面。
- 顶部「继续 · …」大按钮跟着第一节还没上完的课走。

### 今日の一句

- 竖排台词不再被右下角的栞按钮压住最后一个字（底部给按钮留出了位置）。
- 去掉了「第 13 行」这种字幕行号（对学习没有意义）。有说话人或时间时仍然显示「憂 · 12:31」。

### 復習

- 「活用 復習」和「栞をめくる」以前是两行灰色小字，很容易漏看。现在放在「还有到期」标题下面，是两行正常的课表行，显示各自的到期数，点了直接开始。
- 卡片没有到期、但活用或栞有到期时，不再显示「去学ぶ」按钮把人引到别处。

### 其他

- 活用练习的题目卡上不再显示集数和时间码（和自習一致：只看台词本身）。
- 辞書 · 语法页的「実際」栏不再显示「适合做单句精读和语法理解题。」「N4 核心」这类标签式套话（约 240 条）。
- 辞書词条展开后的 AI 要点，又过滤掉了 7 类高频模板话术（「按这一小段理解和跟读」「跟读建议：…」「角色在关键剧情节点使用…」等，每类都在 30 张以上的卡里重复出现）。
