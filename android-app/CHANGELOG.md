## 0.12.0 · 2026-09-28 · 復習 → 知識：无限刷的知识点卡片

### 知識（底栏第 5 个，原来的「復習」）

**为什么改**：0.11.0 的刷卡流只放「今天到期的东西」，刷完四五张就没了，达不到抖音那种一直刷的效果。其实想要的是**知识点卡片流**：把读过的学习文档拆成一张张知识点，无限往下刷，看懂了点 ♥。设计稿在画布「知識 · 知识点卡片流（预览）」页（按你的批注改过：内容全部摊在卡上，不再有展开和相关跳转）。

**现在**：
- 点「知識」进全屏卡片流，**没有尽头**：快刷到底时会自动接上新的卡。
- 第一批知识卡来自《日语如何拆解英语不定式的功能》，一共 **51 张**，按文档顺序推：句型卡后面紧跟它的对比卡、语源卡、陷阱卡和一两道自测。
- **六种知识卡**，右上角标着种类：
  - **句型**：英语对照（go to watch）、形式拆成词块、1–3 个例句（目标部分下划线 + 罗马音 + 中文）、一句话规则、✕ 反例。
  - **对比**：ため か ように 这种，两栏对照表 + 各一个例句 + 一句话怎么选。
  - **陷阱**：✕ 错句（错处划掉）和 ○ 对句上下对照，下面说为什么错。
  - **为什么**：语源和规则背后的原因，比如「ため」本来是名词「為」，一步步画成时间线。
  - **总览**：对照表，比如 to 的十几种用法在日语里各走哪条路。
  - **自测**：填空选择，当场判对错，下面给解析。
- 卡上的内容**全部直接显示**，长一点的卡在卡片里往下滑就能看完。不再有「展开」和「相关」按钮，相关的卡本来就排在后面。
- 知识卡之间穿插**资料里的单词卡**（已校对的读音、释义、备注），每两张知识卡插一张。
- 原来的**到期复习卡**（活用、收藏、错题、苦手）照样穿插在流里，刷的结果照样写回原来的排程。

**♥ = 掌握**：
- 双击卡片，或者点右侧的 ♥，就算掌握了，以后基本不再推。再点一次可以取消。
- 掌握的知识点，**30 天、90 天后各推一道相关的自测题回来考你**；答错会自动取消 ♥，这个知识点重新回到流里。
- 单词卡点 ♥ 等于斩，这个词以后不再出现。
- 到期复习卡点 ♥ 就是原来的「覚えた」（彻底掌握），原来的「覚」章换成了 ♥。

**推送顺序**（全部在手机上算，不需要网络）：没读过的卡按文档顺序先推；读过的隔 1、3、7、14、30 天再回来；♥ 过的只在 30 / 90 天检查时出现。一天读过 10 张卡（或者刷完当天到期的），「最近 12 週」格子点亮。

**顶部**：左边「知識 / 帳面」，右边是掌握了多少（♥ 数）和今天读了多少张。

### 帳面

- 最上面新增**合集**：每份文档一个合集，显示多少张、读过几张、♥ 几张。点一个，就只刷这一个合集（卡片顶上有「只看 ×× ×」，点掉恢复全部）。
- 新增**掌握了的**：所有点过 ♥ 的知识点，可以一条条取消。
- 原来的苦手、到期复习（活用 / 收藏 / 错题本 / 已斩）保留在下面。

### 其他

- 右侧按钮和卡片上的「栞」都改成了「**收藏**」（栞 这个字不好认）。知识卡和单词卡也能收藏。
- 以后的新文档交给 Antigravity 拆成卡片（提示词和校验脚本在 `archive-content-sources/knowledge-cards/`），装好后发一次更新，就会多一个合集。

## 0.11.0 · 2026-09-27 · 復習 改成刷卡流（像抖音一样一张张往上划）

### 復習（底栏第 5 个）

**为什么改**：以前的復習是一页清单。上面的翻卡堆里只有错题和服务端的到期任务，活用和栞只是两行入口，点了就跳到别的页面；左滑右滑翻卡也不会写回任何复习排程（只有错题点「已掌握」会记下来）；苦手和错题本折叠在最底下，基本看不到。

**现在**：点「復習」直接进全屏卡片流，一张卡就是一个今天到期要复习的知识点，往上划就是下一张，下一张卡的边会露在底部。设计稿在画布「復習 · 刷卡流（预览）」页。

- **四种卡**，混在一条流里轮流出现，同一种不会连着刷很多张，逾期久的排在前面：
  - **活用卡**：学过的课里到期的台词。原声自动播放，活用形被网点遮住，只给辞书形和意思提示（例如「取り乱す → ？ 不小心…了」）。轻点翻开，看拆解词块、读音和中文。
  - **栞 · 词汇卡**：大字显示单词，读音先遮住，下面是例句。
  - **栞 · 听辨卡**：栞里存的台词，先只放声音、字被遮住，听完再翻开看原文。
  - **错题卡**：题面，你当时的答案划掉，翻开看正解和解析。
- **手势**：上划 = 记得（进下一张）；下划 = 回上一张；轻点 = 翻开；**双击 = 盖一个「覚」章**，这张彻底掌握。
- **右侧按钮**（按卡的种类出现不同的几个）：栞（把活用台词夹进栞）、讲解、前后句、斩（词汇卡，斩掉以后不再出现）、再来（这一轮 4 张之后再出现一次）、再练（错题直接进练习）。
- **讲解**和**前后句**从底部拉起一个面板，像评论区：讲解是 AI 针对这张卡讲，底下可以打字追问；前后句是这句台词在原作里的前后两句，也能跳到整集字幕。
- 每刷 8 张会插一张**苦手卡**（最近 7 天正确率最低的一类，例如「句末语气 42%」），可以直接去练这一类。
- 最后一张是 **おわり 卡**：这一轮记得、再来、掌握了几张。主按钮「完成」回到今日；「おかわり」是次要按钮，从没到期的卡里随机再刷 10 张（答对不改排程，答错才退回去重新复习）。
- 刷到一半退出，下次进来从上次那张接着刷；过了零点重新生成当天这一轮。当天新到期的（刚学完一课、刚夹进栞、刚答错的）会自动加到这一轮最后。

**刷的结果会写回原来的地方**：
- 活用卡 → 練習用的同一份复习排程（Leitner），盖章就直接进最高档。
- 栞卡 → 栞自己的 1/2/4/8/16 天排程，盖章就是已掌握。
- 错题卡 → 第一次记得，2 天后再出现一次；再记得一次或者盖章，就移出错题本。有对应服务端任务的，同时把结果同步到服务端。
- 每张卡都计入学习日志（答题数和学习时长），刷到おわり卡算完成一次学习，「最近 12 週」格子会点亮。
- 今日时间表「三限 復習」显示的数字，就是这一轮还剩几张。

### 帳面（復習页顶部第二个标签）

- 苦手なところ：最近 7 天各类题的正确率，最低的排最上面。
- 四个本子：活用 / 栞 / 错题本 / 已斩，各自显示到期多少。点一个，就回到刷卡流**只刷这一类**（卡片顶上有「只看 ×× ×」，点掉恢复全部）。
- 服务端到期任务里只有标题、没有题目内容的那些，做不成卡片，列在帳面最下面，点「练习」进原来的练习。

### 其他

- 今日时间表点「三限 復習」、練習页的「复习」入口，现在都直接进復習刷卡流。
- 单词卡备注第三轮装入（Antigravity `ANTIGRAVITY_NOTES3_PROMPT.md`）：重写了 499 条抄台词的备注，其中 323 条换成了新说明，176 条没有值得补充的，就留空。只改备注，读音和释义没动。

## 0.10.1 · 2026-09-27 · 单词卡第二轮数据 + 产品方向讨论记录

### 单词卡（辞書 · 单词练习）

- 修了一个 bug：校对过的单词卡故意把备注留空时（没什么可补充的），辞書和学习卡会退回去显示数据库里旧的、经常出错的备注（例如「EP17筛选…」）。现在校对过的卡片留空就是空。

### 产品方向讨论：要不要改成按 N5 → N1 分级学？（结论：不改）

**起因**：用户提出，最终目标是考过 N2，按一话一话学会让学习的阶梯断掉，是不是应该改成按 N5 → N1 的级别来组织。

**当时查到的数据现状**：

- 单词 3770 个，带 N5–N1 标签（N5 300、N4 468、N3 661、N2 1224、N1 856），但标签是当初 AI 顺手打的：N1 里有「騎士道」「呪術師」「福音書」，N4 里有「ってたの」「ていうか」这种碎片。
- 语法 2966 条，实际只有 1426 个不同句型，级别写法混乱（N4 和 beginner / intermediate 混用），不少条目不是语法点。
- 台词 8560 句，4290 句有原声，大多没有难度标签。
- 已经按知识点组织好的只有自習的 72 课活用。
- 考 N2 约需 6000 词、200 多个语法点，两部动漫的口语台词覆盖不了。

**当时提的方案（大手术）**：以标准 JLPT 大纲为主干，每个知识点优先配原作台词，找不到的用普通例句加 TTS 补；自習改成 N5–N1 五册；練習和復習按级别走；剧集降级成「看番材料」；加定级测试。分三期做，数据最重。

**用户的决定：不做大改。** 理由是这个 App 本来就是以动漫素材为核心收集和组织的，改成以 JLPT 大纲为主干，等于把收集动漫素材这件事本身变得没有意义，产品逻辑反而说不通。

**因此保持现状**：

- 自習仍按知识点（活用 72 课），材料是动漫台词。
- 辞書、課程仍按作品和话组织，練習页里按话的「課程」也保留（审计 A3 就此结案）。
- JLPT 级别只作为辞書里的筛选标签。
- 以后的会话**不要再主动提议改成 JLPT 大纲驱动**。如果将来用户重新提起，上面的数据现状和方案可以直接拿来用。

## 0.10.0 · 2026-09-27 · 产品逻辑大扫除 + 「斩」

这一版把之前攒下的产品逻辑问题一次处理掉，核心是两件事：**练完就结束，不要硬推「再来一回」**；**会的词可以斩掉**。

### 新功能：斩（辞書 · 单词）

看过动漫就会的词（なるほど、ありがとう、大丈夫……）不用再练，可以「斩」掉。斩掉的词：

- 从辞書的词汇列表里消失，也不会再被选进单词练习；
- 如果夹在栞里，会从栞里一起移除；
- 按词本身记（不分哪一话、哪部作品），在一话里斩了，别的话里也不再出现；
- 不会删掉：词汇页顶部多了「已斩 N」，点开能看到全部斩掉的词，展开后点「恢复」就能放回来。

四个入口：

1. **一个词**：辞書 → 词汇 → 点开词条 → 「斩 · 已会」。
2. **一批词**：辞書 → 词汇 → 「選ぶ」，勾选几个词后，底部除了「N 語を練習」还有一个「斩」。
3. **一键斩**：词汇页顶部会显示「动漫里天天听的词 N 个 · 一键斩掉」，一下斩掉这一话里所有这类词。现在内置了约 30 个最常见的（なるほど、ありがとう、すごい、大丈夫、先輩……）；更完整的名单交给 Antigravity 按 3517 个词逐个判断（见下面「数据」）。
4. **学的时候**：单词练习的学习卡底部多了「斩 · 已会」，点了就跳过这个词剩下的题；栞翻卡复习翻开单词卡后，也可以点「早就会了 · 斩」。

### 结算页：练完就结束

以前几乎所有练习的结算页，主按钮都是「再来一组 / もう一回 / 重新练习」，练完了还被推着再练一遍。现在统一成：**主按钮是「完成」（回到进来的地方），「再来」只作为次要按钮，并且只在确实有必要时出现。**

| 练习 | 以前的主按钮 | 现在 |
|---|---|---|
| 辞書 · 单词练习 | もう一回（把同几个词从头再练） | **完成**。答错的词已经在最后重考过一次，并放进了栞 |
| 読空気 | 再来一组 | **完成**；「再来一组」是次要按钮 |
| 活用 復習 | 再来一组 | **完成**；只有还有到期的句子时才出现「再来一组 · 还有 N 句到期」 |
| 基础题库 | 重新练习，旁边还有个莫名其妙的「上一题」 | **完成**；只有答错过才出现「再练一遍」，「上一题」去掉 |
| 課程（按话） | 回到本話 / 再练一次 | 「再练一次」只在有错题时出现 |
| 活用 · 一课的练习 | 下一课 | 不变，另加一个「今天到这」 |
| 自習 | 続き / 次の課 | 不变（本来就是往下走）。「もう一回 了 N 句」这个别扭的标题改成「还要再看的 N 句」 |

另外，一话的課程全部学完后，按钮从「再看一遍」改成「**下一話**」。

### 今日：時間割按主线排

以前「本日の時間割」只按当前这一集排（综合 · 第一話 / 复习 / 读空气 / 跟读），和 App 的主线「自習 → 練習 → 復習」对不上，打开 App 第一眼看不到自習。现在：

- **一限 自習**：接着学的那一课（「第 3 課 · ている」），显示本课学到第几句；**点一下直接开始这一课**，不用再到自習页点第二次。今天学过自習后标成「済」。
- **二限 練習 · 活用**：学过的课里今天到期的句子数，点了直接开始一组。还没学过任何课时不显示。
- **三限 復習**：到期数现在是**卡片 + 栞**的合计（以前只算卡片，数字对不上）。
- **四限 / 放課後**：原来的本集课程、读空气、跟读都还在，排在后面。
- 顶部「继续 · …」大按钮跟着第一节还没上完的课走。

### 今日の一句

- 竖排台词不再被右下角的栞按钮压住最后一个字（底部给按钮留出了位置）。
- 去掉了「第 13 行」这种字幕行号（对学习没有意义）。有说话人或时间时仍然显示「憂 · 12:31」。

### 復習

- 「活用 復習」和「栞をめくる」以前是两行灰色小字，很容易漏看。现在放在「还有到期」标题下面，是两行正常的课表行，显示各自的到期数，点了直接开始。
- 卡片没有到期、但活用或栞有到期时，不再显示「去学ぶ」按钮把人引到别处。

### 其他

- 活用练习的题目卡上不再显示集数和时间码（和自習一致：只看台词本身）。
- 辞書 · 语法页的「実際」栏不再显示「适合做单句精读和语法理解题。」「N4 核心」这类标签式套话（约 240 条）。
