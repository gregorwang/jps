## 2. 新玩法（3 个组件，4 种玩法）

加进 `KatsuyouBook.kt` 的 `KyStep`，`KyokaRules.askable` / `subset` 也要加上，这样能被抽进練習。

1. **`KyStep.Span`：括る / は的地盘**（一个组件，两种玩法）。句子按文节切成块（照 `SPOT` 的写法：`'彼が:kare ga 昨日:kinou …'`），`anchor` = 固定的那一端，`dir`：
   - `start`（括る）：anchor 是被修饰的名词（闭括号），从它往左拖 / 点，找修饰节从哪一块开始。揭晓时画 ［ ］，下面给补洞还原（`gap`：「人が魚を焼く」）和 内/外 标签。
   - `end`（は的地盘）：anchor 是 「〜は」，往右拖，找主题管到哪一块。
   - 手势：容器上 `detectDragGestures` + 每块 `onGloballyPositioned` 记边界，算手指下是哪块，实时铺浅作品色；松手或点一下就判定（和找错一样，不要再加确认按钮）。揭晓后 TTS 整句。
2. **`KyStep.Passage`：主张はどこ**。一段文章拆成编号句子（①②…，每句日文 + 小号罗马音），`ask`（「哪一句是作者的主张？」也可以问靶子、让步、「哪句告诉你心情变了」），点一句判定；揭晓后每句右边出功能标签（一般论 / 让步 / 转折 / 主张 / 理由 / 例），标记词（しかし、もちろん、ではないだろうか）加粗，中文出在句子下面。
3. **`KyStep.Judge`：模擬問題 / 毒を見抜く**（一个组件，两种布局）：
   - 没有 `claim`：题干 + 4 个日文选项选一个（真题形式），揭晓后每个选项标 ✓/✗、干扰项类型（无中生有 / 逆 / 过度一般化…）和为什么。
   - 有 `claim`：给一句选项，选它是哪种干扰项（每题 3–4 个类型标签），揭晓时选项里「有毒」的那几个字划线。
   - 手机上来回看：原文是可折叠卡片，同一篇文章的第一题默认展开，后面的题收成一行「原文 ①–⑩ · 展开」；揭晓后把依据句（`ev`）直接引用在判定下面，不用往回翻。
- 画布：新开一页「自習 · 第九巻 読解（预览）」，4 块画板 `KkBracket`、`KkScope`、`KkClaim`、`KkJudge`（390×844，照 `project/Evidence.dc.html` 的写法和颜色变量）。

## 4. 原文里讲错 / 不准的地方（做的时候按右边写）

1. **南不二男的层级把连用中止放进了 A 类**（L269，L510 第三刀）：连用中止（〜し、〜り、）可以有自己的 が 主语，属于 **B 类**。原文自己的例子「今では人口**が**減り」就是带主语的连用中止。
2. **「は 管到 C 类边界为止」说过头了**（L277–295）：主题 は 是整句的主题，默认管到**句末**；C 类边界（が、けれど、から、し）只是**允许出现新的 〜は**。原文例句「この町は、昔は漁業で栄えたが、今では人口が減り、…人が多い」里 この町 一直是主题（人口 = この町の人口，は-が 句），不是在 が 处结束。3.6 母は…が、…私は… 能换主语，是因为后面出现了新的 私は。玩法 は的地盘 按这个出题：答案是句末，或新 は 前面那一块。
3. **0.3「四段动词以外的很多动词终止形和连体形不同」**（L90）：一段动词（見る、蹴る）也同形；不同的是二段、カ变、サ变、ナ变、ラ变和形容词（し/き）、形容动词（なり/なる）。
4. **2.11 文节切分**（L463）：「新しい本を」是两个文节（新しい／本を）。
5. **第 7 节问2 选项1 的解析自相矛盾**（L1422、L1429）：说它是「老教练的观点」，但问3 选项2 的解析（L1439）又明确说老教练没主张禁止。选项1（数値は…使わないほうがよい）应归为**过度推论**（把「别太依赖」推成「别用」），不是老教练的观点。选项4「取了第一段的常识」也不准：第一段没说「唯一的基准」，是**逆**（⑩ 唯一の根拠とするのではなく）。
6. **目录写「两道题」，第 7 节标题和正文是三道题**（L21 vs L1325）。
7. 4.5 「AはおろかB … B 更极端」（L892）：B 往往是更基本、更容易的那个（漢字はおろか平仮名も書けない），「连 B 都不」才显得极端。卡上写「连更基本的 B 都…」。
8. 2.6 「教育、医療ならびに福祉」（L336）：严格的法律用法里，只有一层并列用 および，ならびに 要在外层包着 および 时才用；判断「の分野における」管三个，靠的是语义，不是 ならびに。
9. 10.5「〜に堪えない：不堪／值得」（L1822）：没有「值得」的意思，「值得」是 〜に堪える（鑑賞に堪える）。（第 10 节不做，汇报里提一句即可。）
10. 附录 A「花道文」（L2130）不是通行的术语，garden-path 句日语叫 袋小路文 / ガーデンパス文。
11. JLPT 部分（第 1 节，不做）：110 分钟、180 分、合格 100、每科基准 19 都对。**内容理解（中文）题数原文写 6，我印象里官方是 9（3 篇×3 题），没来得及在官网核实**（jlpt.jp 的 N1 PDF `guideline/pdf/n1_revised.pdf` 抓不出文字）；如果是 9，「长文 + 主张理解占三分之一以上」也不成立（8/26）。下次核实了再写进汇报。

## 6. 实际做出来的（0.30.0）

- **教科書**：`archive-content-sources/kyoka/dokkai_a.py`（d01–d07）、`dokkai_b.py`（d08–d14、まとめ「読解の道具箱」）、`book_dokkai.py`（装配 + 罗马音小修）。14 課，173 题，目次四节：長い文をほどく / 五步で拆す / 文章の骨組み / 小説を読む。`python build_kyoka.py --ro --book dokkai` 校验并写 `assets/kyoka_books.json`。
- **新玩法**（都在 `KyStep`，已进練習的抽题）：`Span`（括る / は的地盘，`SpanSitting.kt`，拖或点）、`Passage`（主张はどこ，`PassageSitting.kt`）、`Judge`（模擬問題 / 毒を見抜く，`JudgeSitting.kt`，原文可折叠、依据句引用在判定下面）。数据构造函数在 `kk_common.py`：`SPAN`、`SENT`/`PASSAGE`、`JOPT`/`JUDGE`、`CLAIM`。

- **練習**：`LinguisticsScreen.kyokaVolume` 不再 `take(MaxBooks)`，五本书两列排下来（第五本单独一行）。
- **画布**：没有画预览（用户说「不等画布确认」）。

## 8. 经验

- 整句挂在 `line()` 上时 `RO_FIX` 要按**一字不差的整句**配；长句的罗马音有固定的小毛病（私 → watakushi、名词+だ 连写、一日中），统一在 `book_dokkai.py` 末尾的 `_FIX` 里替换，别逐句写 `RO_FIX`。
- `SPAN` 的 `anchor` / `answer` 是块的下标，写完一定数一遍块（我第一遍有三处数错，是 `build_kyoka.py` 的断言之外靠手数查出来的：断言只查范围，不查对不对）。
- 同一篇文章配多道题：`PASSAGE(sents, ask, answer)` 共用同一个 `sents` 列表，`JUDGE` 共用同一个 `src`，每个 item 自带一份拷贝，asset 大了约 100 KB，可以接受。
