# D1 · 课程答题（アイキャッチ / 会話窓各题型 / つづく）— requests

1. **题目的说话人（data）**
   - 页面：会話窓名牌、填空/拼句/跟读的场面立绘、「听一遍，替憂把台词说完」标题
   - 缺：`LessonNode` / `ShadowingSentence` 没有 speaker（同 B.md #2、C.md #2）。
   - 现状：`LessonRules.lineIndex` 按 `sourceLineNo` 从读空气 sceneLines 找说话人、从已加载字幕找时间码；找不到就不显示名牌，立绘和反馈角色退回作品代表角色（`WorkIdentity.representative`）。

2. **设置「进场アイキャッチ」开关 + 当天已播标记（ViewModel / settings）**
   - 页面：Eyecatch（MOTION §3-01：设置里可关；同一天再进同一话缩短到 400ms）
   - 建议：`LabSettings.eyecatchEnabled`；`LabUiState.eyecatchPlayedOn: Map<String, String>`（workSlug:episode → 日期，DataStore）。
   - 现状：始终播放；「当天已播」只记在进程内（`EyecatchMemory`），冷启动后当天会再播一次完整版。

3. **跳过当前题（ViewModel）**
   - 页面：会話窓底栏左侧「跳过」（画布 V3LessonScene）
   - 建议：`LabViewModel.skipLessonNode()`（记为未答并前进），LabApp 传给 `LessonSessionScreen`（加可选参数）。
   - 现状：不显示「跳过」；跟读题左侧是「改用自评」。

4. **每题对错记录（ViewModel）**
   - 页面：つづく「这次记下的 N 句」
   - 缺：`LessonSession` 只有当前题的 feedback，没有逐题结果。
   - 现状：`LessonSessionScreen` 在界面层记下答错的 node id（rememberSaveable），进程被杀后丢失。
   - 建议：`LessonSession.results: Map<String, Boolean>`。

5. **错题的复习时间（ViewModel）**
   - 页面：つづく错题行右侧 mono 标签（画布是「明天」）
   - 现状：统一显示「错题本」。建议给出下一次复习日期。

6. **次回予告的内容（ViewModel / data）**
   - 页面：つづく 次回予告卡（画布：第 3 组 · 跟读 5 句 +一句台词 + 一句提示）
   - 现状：有下一组时显示「第 N+1 组 · 场面名」，听音拼句/跟读场面从 `uiState.shadowing` 里取本组之后的第一句当预告台词；没有下一组时预告下一场面（只展示，按钮是「回到本話」，因为 `LessonSessionScreen` 没有「开始下一场面」的回调）。
   - 建议：`LabUiState.nextLessonPreview { title, count, sampleLine }`，以及 `startNextScene()`。

7. **原声时长（data）**
   - 页面：原声按钮「原声 0:03」、打字机与音频对齐（总时长 = 音频时长 × 0.9）
   - 现状：`PromptAudio` 没有时长，按钮只写「原声 / 朗读」，打字机按默认 35ms/字。

8. **角色立绘（asset）**
   - 页面：会話窓上方的场面格（画布是整幅立绘）
   - 现状：用组件库 `PortraitPanel`（网点底 + 120dp 头像）代替，等素材改造。
