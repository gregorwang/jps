# D2 requests (读空气 / 基础题库答题)

## 1. Read-air skip action (ViewModel)
- Missing: no way to skip the current read-air question without answering.
- Screen: `session/ReadAirSession.kt` (bottom bar left quiet button 「跳过」).
- Proposal: `LabViewModel.skipReadAirExercise()` → advance to the next unanswered exercise; LabApp passes it as `onSkip`.
- Workaround: `ReadAirSessionScreen` has an optional `onSkip: (() -> Unit)? = null` (additive, contract unchanged); 「跳过」 is hidden while it is null.

## 2. SpeechBubble content slot (component)
- Missing: `ui/design/SpeechBubble` only takes a plain string, so the 着重号 (EmphasisText) can't be drawn inside it after a correct answer.
- Screen: read-air / foundation dialogue panels.
- Proposal: `SpeechBubble(..., content: @Composable () -> Unit)` overload, or an `emphasis: List<IntRange>` + `emphasisVisible` parameter.
- Workaround: `ReadAirParts.kt` `ReadAirBubble` uses SpeechBubble when nothing is emphasised, otherwise a private copy of its frame around EmphasisText.

## 3. Foundation question → work (data)
- Missing: `FoundationQuestion` has no workSlug, so the feedback character can't be chosen per question.
- Proposal: expose the active course's workSlug in `FoundationTrainingState` (or pass it in `FoundationActions`).
- Workaround: `FoundationRules.workSlugFor(AjlTheme.work.hue)` maps the current theme hue to k-on / re-zero; 藍 falls back to a 「学」 kanji avatar.

## 4. Shared つづく (package D1)
- Read-air and foundation set ends use a private simplified つづく (`ReadAirTsuzuku` in `ReadAirParts.kt`: title, tally, missed lines, one ink button + one quiet button).
- After merge, switch both to D1's `TsuzukuScreen` if its API accepts custom tally / noted lines / actions, and delete `ReadAirTsuzuku`.

## 5. Foundation exit from 言語学 (package C)
- `LearnScreen.kt` currently calls `FoundationSession(..., onExit = {})`; the × button and back gesture do nothing until C wires `onExit` to leave the session.
